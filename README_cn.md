## 产品概述

JetAuto是幻尔科技开发的AI驱动自主移动机器人，专为NVIDIA Jetson平台设计。具备先进的导航、ROS集成和智能控制系统，JetAuto为移动机器人研究、教育和开发提供了强大的平台。
